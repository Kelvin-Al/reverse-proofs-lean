# 小型逆向证明模型

模型用 14 个状态特征为 7 类 tactic 打分，共 98 个可训练权重。它从零初始化，在 CPU 上用 NumPy 训练。固定的逆向规则依据当前目标生成候选前驱状态和具体 tactic，模型决定优先尝试哪一类。训练过程只更新打分权重。

数据来自两份命题逻辑实验结果，共 28 条通过 Lean 完整重放的逆向轨迹和 199 条通过验证的转移。按最终命题分组，忽略原子命题的一致重命名。同一组只会进入训练集或留出集。首轮在 22 条轨迹的 156 步上训练，并留出 6 条轨迹的 43 步。局部步骤可以跨命题重复，报告会另计训练集中未出现过的完整转移。

频率基线按训练集中的 tactic 次数排序，与学习模型共用候选规则和生成预算。留出集评估记录参考 tactic 类别的排名，并让 Lean 检查排名最高的可构造候选。完整生成实验独立从 `[]` 开始，每种策略使用相同的 12 个随机种子，最多逆推 8 步，至少走 4 步才接受闭合状态。Lean 从生成的命题正向重放各步，并检查公理依赖。两组指标分别衡量排序和最终证明的有效性。

## 首轮结果

| 数据 | 训练步数 | 参考 tactic 类别排第一（频率 → 学习） | 完整证明通过 Lean（频率 → 学习） |
|---|---:|---:|---:|
| 手写规则 | 76 | 7/20 → 15/20 | 0/12 → 2/12 |
| 手写规则和历史对话模型轨迹 | 156 | 15/43 → 30/43 | 0/12 → 2/12 |

在纯规则实验中，两种策略分别提出的 20 个单步候选都通过 Lean。学习策略生成的两条完整证明均无公理依赖，忽略原子命题重命名后都对应 `P → P ∧ P`。目前只在小规模命题逻辑和这组固定逆向规则上验证了学习排序的效果。

## 第二轮有界搜索

首轮的 10 条失败轨迹在第 3 步都累积到了三个目标，最后耗尽了 8 步预算。其中 7 条在余下五步只用 `left` 或 `right` 反复扩大首个目标，其余两个目标始终留在队列中。另有三条一度合并了目标，最终仍有至少两个未合并。这 10 条轨迹的 80 条局部转移全部通过 Lean 单步检查。

第二轮加载同一个 98 权重的纯规则模型。搜索保留不同 tactic 和前驱状态的备选分支，每次最多取出 64 个状态。优先级结合 tactic 排名与闭合所需步数的下界。按原子一致重命名合并等价状态，每组种子内优先返回此前未生成的命题。频率基线使用同一个解码器、搜索和去重规则。证明仍需 4 至 8 步，Lean 正向检查每个状态并确认无公理依赖。

| 种子 | 排序 | 贪心通过 | 有界搜索通过 | 搜索去重命题数 | 联结词结构数 | 搜索取出的状态数 |
|---|---|---:|---:|---:|---:|---:|
| 0–11 | 频率 | 0/12 | 12/12 | 12 | 3 | 552 |
| 0–11 | 学习 | 2/12 | 12/12 | 12 | 5 | 447 |
| 100–111 | 频率 | 0/12 | 12/12 | 12 | 3 | 551 |
| 100–111 | 学习 | 2/12 | 12/12 | 12 | 5 | 421 |

联结词结构忽略原子名称和原子是否相同，保留 `→`、`∧`、`∨` 组成的树。相同搜索条件下，两种排序的通过率持平，学习排序覆盖了更多结构并取出了更少的状态。本轮通过的证明都没有用到 `cases`。

## 运行

复用已有的 Anaconda `uni_env`，确保其中有 Python 3.10+ 和 NumPy，并使用仓库固定的 Lean 4.19.0。从仓库根目录在 Anaconda Prompt 中执行以下命令。若 Lean 已在 `PATH` 中，可省略 `--lean`。

```powershell
conda run -n uni_env python -X utf8 training/train.py --lean C:/path/to/lean.exe --output training/runs/linear-baseline
```

加上 `--rules-only`，可将训练和留出评估都限定在手写规则轨迹上。也可以直接调用 `uni_env` 内的 `python.exe` 执行相同的 Python 参数。

每次指定一个新输出目录。`model.json` 保存权重和频率基线，`summary.json` 保存切分与指标，`trained.json` 和 `frequency.json` 保存逐步预测、完整生成轨迹和 Lean 检查记录。

用 `--rules-only` 生成的检查点或仓库中的[纯规则检查点](results/rules_model.json)重跑第二轮。仓库保留[训练结果](results/rules_training.json)和[搜索对照结果](results/search_comparison.json)。重新运行还会按种子组和策略保存逐步轨迹与 Lean 源码。

```powershell
conda run -n uni_env python -X utf8 training/search.py --model training/results/rules_model.json --lean C:/path/to/lean.exe --output training/runs/search-baseline
```
