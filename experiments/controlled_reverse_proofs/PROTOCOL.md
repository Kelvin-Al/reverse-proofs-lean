# 受控逆向证明生成

## 问题

给生成器一个证明结构要求，不给目标命题或已有证明。生成器要产出一个命题及其 Lean 证明，并满足指定的分支结构。

- **单侧嵌套（chain）。** 有且只有两次析取消去。第二次只发生在第一次的一个分支里，左右均可。
- **双侧嵌套（balanced）。** 有且只有三次析取消去。第一次的两个分支各再拆一次。
- 每个分支引入的局部证据都必须出现在该分支的 Lean 证明项中。嵌套分支以该局部证据为再次拆分的对象，也算使用。每次拆分的两个析取项必须有不同类型。这是证明项中的出现检查，不判定逻辑上的不可替代性。

每种结构、每个方法各三次尝试。每条证明最多 16 条 tactic 指令，只用四个原子命题和 `→ ∧ ∨`。单个公式最多 12 个联结词。允许的 tactic 是 `intro`、`exact`（含合取投影）、`apply`、`constructor`、`left`、`right` 和 `cases ... <;> rename_i ...`。最后一种记为一条指令。

## 三组

1. **LLM 逐步逆向。** 本对话模型按照每条轨迹的结构要求，从空目标列表起步。每轮为每条仍在运行的轨迹提出一条逆向转移和完整前驱状态。Lean 验证上一轮之后才提出下一轮。每步一条候选，无重试。局部证明假设全部抽象完、只剩一个目标时停止。
2. **手写规则逆向。** 从空目标列表起步。规则组直接以指定的分支形状为模板，按右到左的顺序逆向增加叶子，必要时逆转注入或函数应用，再逆转 `cases` 合并子树。每种结构用三个固定的叶子类型与局部推导安排。使用与 LLM 逐步逆向相同的 Lean 检查。
3. **LLM 一次生成。** 本对话模型一次给出每条命题和完整正向 tactic 序列。该批次在完整对照运行前固定，未使用失败反馈改写。

两组 LLM 都是本对话内的提示式生成。没有训练独立模型，候选不是独立随机样本。各组匹配生成条数和 tactic 指令上限，未匹配 token、耗时或 Lean 调用次数。小规模对照适合检查能否满足约束。

## 验证

逆向边在 Lean 中检查实际目标数、顺序、局部假设和类型，再完整正向重放。结构检查根据实际 Lean 目标追踪 `cases` 的分支祖先，并读取各分支元变量的证明项，检查该分支新引入的变量是否出现。每条最终证明还必须没有公理依赖。

三个负对照分别交换了目标顺序、把两个 `cases` 放在不同的并列目标上、以及构造了正确的嵌套形状但忽略一个分支假设。后两条单独作为定理可通过，结构检查应拒绝。

## 复现

需要 Python 3.10+ 和 Lean 4.19.0。安装 Lean 后，在解压目录执行：

```sh
python3 experiment.py
```

也可用 `--lean /absolute/path/to/lean` 指定 Lean。脚本从冻结的候选重新执行全部 Lean 检查，并写出 `results.json`。逐轮门控使用 `--gate-cache /path/to/cache.json`，该缓存不是复现最终结果的依赖。原始模型候选在 `llm_rounds/` 和 `direct.json`，规则法在 `rules.py`。

## 结果

| 指标 | LLM 逐步逆向 | 手写规则逆向 | LLM 一次生成 |
|---|---:|---:|---:|
| 证明成立并满足单侧嵌套要求 | 3/3 | 3/3 | 3/3 |
| 证明成立并满足双侧嵌套要求 | 3/3 | 3/3 | 3/3 |
| 组内不同联结词结构 | 6 | 6 | 6 |
| 证明指令数范围 | 6–13 | 6–14 | 6–16 |
| 通过的逐步逆向转移 | 60/60 | 59/59 | 不适用 |

按公式语法树统计，忽略原子名称及相等关系。逆向 LLM 与规则组共享 3 种结构，与直接 LLM 共享 1 种。规则组与直接 LLM 共享 1 种。三个负对照均被相应检查拒绝。

一条双侧嵌套轨迹在第 13 步得到
`((P ∨ Q) → R) → ((P ∨ Q) ∨ (R ∨ (R ∧ S))) → R`。
左子树各叶把证据注入 `P ∨ Q` 后应用给定函数。右子树的两个叶分别提供 `R` 或从 `R ∧ S` 投影出 `R`。四个叶子都使用了各自收到的证据。

两种拓扑均可用树形规则直接安排。这个任务验证了从空状态按指定结构构造证明的可行性，三组的结构命中率达到同一上限。
