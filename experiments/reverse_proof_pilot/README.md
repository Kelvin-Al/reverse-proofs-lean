# 逆向证明生成小实验

这个原型检验一个局部问题：从一个已有证明出发，模型能否提出一个新的命题和一段可执行的证明前缀，使 Lean 恰好留下一个由种子证明闭合的目标。

## 复现

需要 Python 3.10+ 和 Lean 4.19.0。已有 elan 时，解压后进入本目录执行：

```sh
python3 experiment.py
```

也可运行 `python3 experiment.py --lean /absolute/path/to/lean`。使用 Lean 自带的库，无需安装 mathlib。运行会更新 `results.json`，其中包含原始候选、每条实际提交给 Lean 的源码、诊断信息和汇总。要替换模型输出，可以传入 `--proposals /path/to/other.json`，文件结构参见 `llm_proposals.json`。

## 协议

- 种子是合取交换、析取消去、蕴含复合。每个种子每组尝试 8 个候选。候选只包含四个命题变量和三类联结词，最多 12 个联结词。两组使用相同验证器和相同候选数，生成耗时和 token 成本未做匹配。
- 规则组使用 8 个可检查的类型变换模板，包括合取携带、析取分支和继续式。模板都作用于种子最外层的蕴含式。它是一个确定性的小基线，结果只代表这组规则。
- LLM 组使用本对话模型依据 `prompt.txt` 一次性提出的 24 对命题与证明项。生成结果在 Lean 检查前冻结，没有用验证器反馈改写，也没有做独立 API 抽样或微调。重跑脚本使用同一批候选。
- 验证器把候选里的唯一 `seed` 替换为带种子类型的 Lean 证明洞，执行 `refine`，检查剩余目标的类型，再用原始证明项补齐并检查无公理依赖。另有一个应通过和一个应失败的验证器对照。
- 联结词结构按语法树计数，保留联结词、左右顺序和括号结构，忽略原子名称及重复关系。另报告保留原子相等关系、只消除原子改名的去重计数。两种去重都按语法进行。

## 结果

| 指标 | 规则 | LLM |
|---|---:|---:|
| 通过 Lean 重放 | 24/24 | 23/24 |
| 去除原子改名后的命题数 | 24 | 23 |
| 不同联结词结构数 | 24 | 23 |
| 有效命题的平均联结词数 | 6.62 | 6.74 |

两组共享 1 种联结词结构，规则组独有 23 种，LLM 组独有 22 种。LLM 的唯一失败来自析取消去种子。候选试图用两条不同结论的分支构造析取结论，但复用的种子类型要求两个分支都返回原来的 `R`，且提交的包装项有类型错误。

另做了一个独立的诊断对照，未计入上表。目标是
`((P → R) ∧ (Q → S)) → (P ∨ Q) → (R ∨ S)`。
使用同一个新包装项，固定种子类型会失败，把析取消去种子中的 `R` 实例化为 `R ∨ S` 后通过。种子证明项保持不变。这个对照展示了显式类型实例化如何扩展一个证明种子的用途。

这是单步命题逻辑试验。结构数是表面语法指标，不能代表命题难度、语义新颖性或训练价值。实验未运行 jixia 数据提取、微调或下游 prover 训练。
